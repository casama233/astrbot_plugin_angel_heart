# AngelHeart — 智慧群聊／私聊互動插件

[简体中文](README.md) · **繁體中文** · [English](README.en.md)

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

文件對應插件版本：**0.9.3**。

AngelHeart 是專為 [AstrBot](https://github.com/Soulter/AstrBot) 設計的智慧群聊／私聊互動插件，使用**前台、秘書、助理**三種職責與**離場／在場**兩種群聊狀態，減少不必要插話並保持適當回覆節奏。

## 三角色架構

| 角色 | 職責 | 模型 |
| --- | --- | --- |
| 前台 | 記錄訊息、管理帳本和排程入口 | 不使用 LLM |
| 秘書 | 檢查聊天節奏，決定是否需要助理接話 | 輕量模型 |
| 助理 | 實際產生回覆 | 主模型 |

處理路徑：**訊息 → 前台入帳 → 秘書巡檢 → 判斷是否接話 → 助理回覆**。秘書決定不回覆時，助理不會喚醒。

## 群聊兩種狀態

- **離場（`NOT_PRESENT`）**：只記錄，不主動參與。收到 @ 或命中稱呼才會入場；可選擇對重複或密集訊息作一次性回覆，但仍維持離場。
- **在場（`OBSERVATION`）**：被點名後繼續觀察，在群聊稍微安靜時由秘書決定接話；超過參與時間上限後，在下一則訊息返回離場。

**巡檢**：點名時先等待使用者補充，普通訊息則在對話安靜後再檢查。新訊息會替換舊的等待邊界；同一會話只執行一輪秘書判斷。點名可升級原有巡檢而不重複建立任務。助理回覆後的休息門閂防止反覆插話；直接點名仍須遵守忙碌與休息限制。

## 能量與節奏

每個群組的助理各有能量值；普通巡檢前按經過時間恢復。長回覆消耗更多能量，預設：

| 項目 | 數值 |
| --- | --- |
| 初始值／上限 | `100` |
| 下限 | `-100` |
| 每秒恢復 | `0.6` |
| 每次回覆基本消耗 | `14` |
| 每有效字元消耗 | `0.12` |

公式：`14 + 有效字元數 × 0.12`。能量按群組儲存在記憶體，插件重啟後重設。普通秘書巡檢受能量門檻限制；**點名與離場一次性應答不受能量門檻**（但仍遵守其他執行限制）。

## 上下文與相依

插件管理群聊脈絡及私聊脈絡，提供可配置的觸發、等待、冷卻和模型路由。可搭配 [Angel Memory](https://github.com/kawayiYokami/astrbot_plugin_angel_memory) 補充長期記憶、筆記、重排和學習功能；Angel Memory 是選用的互補插件，**AngelHeart 的基本回覆功能不以其為前置相依**。

## 安裝

需已安裝 [AstrBot](https://github.com/Soulter/AstrBot)、**Python 3.10+**，以及至少一個可用模型 Provider。可在 AstrBot 插件市場搜尋「天使之心」安裝，或將源碼放入 AstrBot 插件資料夾，並在 WebUI 啟用。
